# About This Project: Resume

Creating a single page site to display my resume contents was the first project I completed after learning basics of React development. This project allowed me to practice building reusable components with content provided by arrays with my information and passed in to the components as props.

I also added a section to the side demonstrating the ability to connect to an external API and return a gif based on a user's selection, which at the time was a new skill I had learned.

_Tech Stack_

- React
- JavaScript
- HTML
- CSS

_Development Growth_

Although I have regularly created more in depth projects since displaying my resume, I still include it on my portfolio to show the progression I have made since my first published site.
